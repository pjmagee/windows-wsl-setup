# Site (Astro + Bun)

Static GitHub Pages for **Windows WSL Manager**. First doc is Getting started (`/docs/getting-started/`). `/docs/welcome/` redirects there.

```
cd site
bun install
bun run dev
bun run build
```

Published at `https://pjmagee.github.io/wwm/` when the **GitHub Pages** workflow runs (Settings → Pages → Source: GitHub Actions).
